# Matriz

Matriz is a simple web application for teams to organize projects and track their tasks. It addresses the need for a lightweight alternative to larger tools such as Jira for a company of roughly 500 Project Managers and Software Engineers.

## MVP objectives

- Organize tasks under projects and teams.
- Let Project Managers manage projects and tasks.
- Let Administrators manage users and team membership.
- Give Software Engineers read-only visibility of teams, projects, and tasks.

## Planned MVP features

Project and task creation, editing and viewing; project archival; role-based access; user creation and team assignment; task effort, status, dates, project, team, and Software Engineer assignee.
